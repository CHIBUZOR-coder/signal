====================================
WHAT I'LL SAY — SECTION C, BEAT BY BEAT
====================================

1. OPEN (bridge from Aldor demo)
"What you just saw is live. What I'm about to show isn't built yet — but
it's built on the same rule: the client never decides anything, it only
renders what the API sends it."

2. FRAME IT (the four questions)
"Every executive asks something different. SIGNAL is built to answer all
four from one set of numbers."
- CEO: Will we hit the target, what changed, what needs me?
- CFO: Can we trust the value — what's validated, banked, at risk?
- Sponsor: Is my workstream covered, what must happen by next review?
  (NOTE: no screen exists for Sponsor in the deck — say so if asked,
  don't invent one)
- Owner/Finance: What must I update, evidence, validate or escalate now?

3. THE LIFECYCLE (one app, two threads)
"SIGNAL tracks every promised value outcome from first idea to proven,
banked result." Nine stages: Opportunity -> Value Case -> Gates (PG0 to
PG5, six levels, PG0 still counts at 25%) -> Commitment -> Delivery ->
Validated -> Banked -> Embed -> Sustain. Click through fast — establishing
there's a real spine, not teaching each stage.

4. DEMO THE CEO SCREEN (strongest ground — real deck numbers, slide 11)
Walk in order: Target $50m -> MAPV $47m (94% coverage, $3m gap) ->
Forecast $44m ($6m below target) -> Delivered $31m (Finance-validated) ->
the Value-at-Risk line (Bank $6.5m CFO certified, Tender authority 12
days waiting, Supply Chain $3m gap).
Same $50m goal, four levels of proof — a single blended number would
hide the gap between "looks healthy" and "actually proven."

5. SWITCH ROLES LIVE
"The field list is confirmed, the exact layout isn't." Click CFO (or
Owner/Finance) — show the SAME underlying $3m Supply Chain issue from a
different angle: CFO sees it as "Challenged value," Owner sees it as a
task ("resubmit evidence, due in 3 days"), Finance sees it as something
to validate. Point at the "never shown here" strip at the bottom — same
across every role, proof the simplicity is deliberate.

6. DRILL DOWN
"Watch the breadcrumb." Click all 4 levels fast — Portfolio -> Supply
Chain $3m gap -> Supply Chain Consolidation -> Evidence. Context never
resets, no matter how deep you go.

7. TIE BACK, HAND OFF
"Delivery and Forecast move constantly; Commitment and Gate history never
do, once locked. That line is what Eseigbe's about to defend in detail."
One or two sentences, then stop — opening the door to Section D, not
walking through it.

8. CLOSE
"Sophisticated underneath. Simple on screen."
